# Presentations

Each deck is a Markdown file in `docs/presentations/`, rendered full screen
with reveal.js. The same file is listed in `llms.txt` and the agent API, so an
agent can read the slides and speaker notes as text.

## How to use a deck

- **→ / ←** move between sections; **↓ / ↑** move through the slides in a
  section. **Space** walks through everything in order.
- **Esc** shows an overview of all slides, **S** opens the speaker notes,
  **F** goes full screen.
- The **Print / PDF export** link listed for each deck below opens a print-ready view.

Decks are split into sections, so a presenter short on time can skip a
section with a single press of →.
