# Sharing Stuff

A set of pinboards for what you want to pass on after the unconference. Each
board starts empty and grows as people add to it.

- [Recommended books](./books.md): books worth reading, with one line on why.
- [Recommended movies](./movies.md): movies and series worth watching.
- [Kudos](./kudos.md): thanks to roles, sessions and groups, without names.
- [Impressions](./impressions.md): anonymous one-liners about the unconference
  as a whole.

To add an entry, open a pull request that edits the board page, or post it in
the SoCraTes Slack at <https://socratesbe.org/slack/> and an organiser will add
it.
