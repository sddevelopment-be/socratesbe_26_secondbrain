# Contribute

Everything on this site is a Markdown file in
[the repository](https://github.com/sddevelopment-be/socratesbe_26_secondbrain).
To contribute, open a pull request. The GitHub web editor is enough.

- [Add a session note](./add-a-session-note.md): the most common
  contribution.
- [Working with agents](./working-with-agents.md): let an LLM read the site
  or draft a page for you.
- [Run the site locally](./run-locally.md): preview your change before you
  open a pull request.
