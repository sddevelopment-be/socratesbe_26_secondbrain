# Development

This second brain is written by many hands: participants in a browser,
participants with an editor, and agents working on someone's behalf. These
pages describe the rules that keep the shared mainline trustworthy for all of
them.

- [Protecting the mainline](./branch-protection.md): why `main` is protected
  when a crowd or an agent swarm collaborates, and exactly which rules to set.
