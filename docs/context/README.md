# The Unconference

SoCraTes BE is the Belgian edition of SoCraTes, the *Software Crafting and
Testing* unconference. It is organised by volunteers, for software crafters,
by software crafters.

- [About SoCraTes BE](./about.md): the format, the marketplace and the spirit.
- [Practical information](./practical.md): dates, venue and where to find
  people.
- [Audience](./audience/README.md): who this second brain is written for.
