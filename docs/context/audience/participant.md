# The participant

The participant reads this site in a browser, often on a phone between
sessions. They want to find things fast: a session, a link someone
mentioned, the name of a kata.

When they contribute, they write Markdown in the GitHub web editor or in their
own editor, or they ask an agent to draft a page from their notes. See
[Add a session note](../../guides/add-a-session-note.md).
